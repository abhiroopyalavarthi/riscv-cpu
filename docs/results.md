# Benchmark results

Generated by `make bench` (scripts/bench.py). Numbers cover only the benchmark kernel, read from the CPU's own performance counters.

Caches: direct-mapped, 16-byte lines, write-through / no write-allocate, 10-cycle miss penalty. RAM without caches is single-cycle, so the cached configs are *slower* than `bp`: they model a realistic slow memory behind the cache.

## Configurations

| Config | Description |
|---|---|
| `single` | single-cycle |
| `pipe` | 5-stage pipeline, predict not-taken |
| `bp` | pipeline + BTB/2-bit predictor |
| `c256` | pipeline + BP + 256 B I$/D$ |
| `c1k` | pipeline + BP + 1 KB I$/D$ |
| `c4k` | pipeline + BP + 4 KB I$/D$ |

## Control flow

`redirects` = times the pipeline had to flush and refetch (2 cycles each). Without a predictor that's every taken branch or jump; with one it's every misprediction.

| Benchmark | branches+jumps | redirects (`pipe`) | redirects (`bp`) | BP accuracy |
|---|---|---|---|---|
| sort | 31,270 | 15,767 | 267 | 99.1% |
| matmul | 174,898 | 99,409 | 18,892 | 89.2% |
| crc32 | 4,100 | 4,099 | 5 | 99.9% |
